# 成就系统

共 50 个成就，涵盖陪伴 7 项、互动 3 项、成长 15 项、任务 19 项、衣装 3 项、升星 3 项。

面板「成就」页面展示总收集数量和比例、每项成就的条件和进度，以及解锁日期。
支持分类、已解锁/未解锁筛选、关键词搜索，以及按最近解锁或即将解锁排序。
新成就解锁时显示提示，点击可打开收藏页。

## 统计规则

- 陪伴分钟：沿用应用每分钟的经验结算计时；退出或休眠期间不会补算离线分钟。
- 陪伴天数：本地自然日，在当天至少结算一次陪伴分钟即计为一天，不要求连续。重复启动不会增加当天计数。
- 互动次数：点击头、耳、手臂、腿或尾巴等模型命中区域；点击打开面板的毛球区域或透明空白不计入。关闭触摸音效仍计入互动。
- 成长进度：保存属性、同时满足的五项属性最低值和持有经验的历史最高值。消耗经验或升星后的属性降低不回退进度。
- 任务计数：仅结算时累计，取消或移除排队任务不计。成功数、失败数、不同任务种类及队列成功数独立保存，不受最近 10 条任务历史限制。
- 连胜：任务失败会把当前连胜归零，进度显示历史最佳连胜。取消任务不影响连胜。
- 重新站起来：某次任务失败后，下一次结算的任务成功即解锁；重启会保留此前的失败状态。
- 解锁永久保留，并保存首次解锁时间。重启不会重复计数或重复解锁。
- 旧存档：依据当前属性、衣装、星级、最近任务历史和可确认的已完成任务补发，解锁日期为补发日期。无法恢复旧版没有保存的陪伴时长、互动次数和已丢失的历史任务次数。
- 成就仅提供收集目标，不发放属性或经验奖励。

## 实现与验证

定义和条件位于 `src/Achievements.hpp`，统计保存在 RocksDB 的 `achievements.state` 中。
任务成就和奖励、任务结算状态在同一 WriteBatch 内提交，防止退出后重复统计。
`GET /api/achievements` 返回列表与收集数量；SSE 的 `ACHIEVEMENT_UNLOCKED` 消息驱动解锁提示。

```sh
bash build-scripts/test_achievements_macos.sh
bash build-scripts/test_task_queue_macos.sh
```

前者覆盖全部 50 项的解锁边界、日期、连胜、序列化及异常存档；后者覆盖真实任务结算、
成就与任务的共同持久化、重启不重复计数、旧存档迁移、陪伴与并发互动计数。
